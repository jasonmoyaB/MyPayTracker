Política de privacidad de MyPayTracker

Última actualización: 28 de octubre de 2026.

MyPayTracker es una aplicación de uso personal de un único usuario, su dueño. No está abierta al público.

Qué datos lee

Con permiso de solo lectura de Gmail (gmail.readonly), la aplicación lee únicamente los correos de notificación de BAC Credomatic (compras y SINPE) de la cuenta del dueño. No lee, modifica, envía ni borra ningún otro correo.

Para qué los usa

De cada correo extrae monto, moneda, fecha y comercio para calcular el saldo disponible del dueño. No se usan para publicidad ni para ningún otro fin.

Dónde se guardan

Los movimientos extraídos se guardan en una base de datos privada de Supabase, protegida por inicio de sesión y reglas de acceso por usuario. El contenido completo de los correos no se almacena.

Con quién se comparten

Con nadie. Los datos no se venden, no se comparten con terceros y no se transfieren fuera de lo necesario para el funcionamiento descrito.

El uso de la información recibida de las API de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso a Gmail se puede revocar en cualquier momento desde myaccount.google.com/permissions.

Contacto

Por el correo de soporte indicado en la pantalla de consentimiento de Google de esta aplicación.
