# Diseño de MyPayTracker

Dirección visual propuesta: **minimalismo cálido, claridad financiera y personalidad discreta**.

La interfaz debe permitir entender el dinero disponible de un vistazo y registrar movimientos sin esfuerzo. El interés visual nace de la tipografía, el espacio y la jerarquía; el color acompaña esas decisiones.

## Guías

- [Paleta de colores](./paleta-de-colores.md): colores, roles, tokens CSS y contraste.
- [Fundamentos de UI/UX](./fundamentos-ui-ux.md): jerarquía, tipografía, componentes, estados y movimiento.

## Criterio para nuevas decisiones

1. ¿Ayuda a entender el saldo o completar una tarea?
2. ¿Mantiene una jerarquía clara y poco ruido visual?
3. ¿Funciona con teclado, en móvil y sin depender solo del color?

Estas guías parten de `docs/constitution.md`. Son la base para implementar la futura interfaz; todavía no representan pantallas implementadas.
